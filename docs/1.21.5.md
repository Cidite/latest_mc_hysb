# 유틸/편의성 모드
[Bobby](https://modrinth.com/mod/bobby) - 먼 거리에 있는 청크를 언로딩하지않고 그대로 보여줌

[Break Free](https://modrinth.com/mod/breakfree) - 드릴핑 해결 모드

[Chat Calc](https://modrinth.com/mod/chat-calc-kt) - 채팅에 수식 입력하면 답 나오는 모드. 사칙연산, 로그, 지수같은 고급 수학 연산도 지원함.

[Chat Patches](https://modrinth.com/mod/chatpatches) - 불편한 채팅을 개선하는 모드.

[Dynamic FPS](https://modrinth.com/mod/dynamic-fps) - 백그라운드, 잠수, 닫은 상태일때 FPS 제한을 설정함. 본인은 20FPS 설정하는편.

[Entity View Distance](https://modrinth.com/mod/entity-view-distance) - 개체마다 렌더링 거리를 조정 가능함.

[Gamma Utils](https://modrinth.com/mod/gamma-utils) 또는 ~~[Methane](https://modrinth.com/mod/methane)~~(개발 중단) - 밝기를 최대치로 설정.

ItemSwap - NEU에 있는 아이템락 그거

[Model Gap Fix](https://modrinth.com/mod/modelfix) - MC-73186(1.8~) 버그를 고치는 아이템 모델 버그 픽스

[No Chat Reports](https://modrinth.com/mod/no-chat-reports) - 채팅 신고가 불가능하게 만듬.

[No Double Sneak](https://modrinth.com/mod/no-double-sneak) - 웅크리기 2번하는 성가신 버그 픽스

~~[NoChangeTheGame](https://modrinth.com/mod/nochangethegame) - 게임의 대부분 역학을 1.8에 맞춤(수영 금지, 엎드리기 금지)~~ 1.21.5 미지원

[Particle Core](https://modrinth.com/mod/particle-core) - 파티클 세부 설정 가능

[Remove Reloading Screen](https://modrinth.com/mod/rrls) - 리소스팩 리로딩할때 모장 로고 숨김

Simple Health Bar - 체력바를 멋지게 바꿈. 흡수체력 지원.

[Slyde](https://modrinth.com/mod/slyde) - 모장에서 정한 설정 값을 우회가능.(밝기 1300%, 렌더 거리 1 등...) Cursed한 모드라 설정 잘못 만지면 크래시 발생함.

[Tooltip Scroll](https://modrinth.com/mod/tooltip-scroll) - 툴팁을 스크롤하는 모드. 하픽 스블 특성상 툴팁이 오지게 긴 경우가 많아서 필수.

[View Model](https://modrinth.com/mod/no-ones-view-model) - 1인칭 시점의 손과 아이템의 모델의 위치를 바꿔주는 모드.

[Zoomify](https://modrinth.com/mod/zoomify) - 줌모드
