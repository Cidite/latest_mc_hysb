# 최적화 모드
[Entity Culling](https://modrinth.com/mod/entityculling) - 벽 너머에 있는 엔티티 렌더링 중단. 특히 벽 너머에 있는 몹이 많은 던전 특성상 좋은 효과를 보임.

Faster Random - 랜덤 함수 개선 모드. 클라이언트는 약간의 성능 향상

[FerriteCore](https://modrinth.com/mod/ferrite-core) - 메모리 최적화 모드

ImmediatelyFast - 엔티티/블록/텍스트/HUD 렌더링 최적화. **호환성 문제가 좀 있음.**

Nvidium - 엔비디아 그래픽카드 있으면 성능 더 좋아짐

ScalableLux - 빛 연산 최적화. **Methane와 호환안됨**

[Sodium](https://modrinth.com/mod/sodium) - 설명이 필요한가?

[Sodium Extra](https://modrinth.com/mod/sodium-extra) - Sodium 추가 설정

Very Many Players - 많은 플레이어가 있을때 최적화

# 유틸/편의성 모드
Bobby - 먼 거리에 있는 청크를 언로딩하지않고 그대로 보여줌

Break Free - 드릴핑 해결 모드

Chat Calc - 채팅에 수식 입력하면 답 나오는 모드. 사칙연산, 로그, 지수같은 고급 수학 연산도 지원함.

Chat Patches - 불편한 채팅을 개선하는 모드.

[Dynamic FPS](https://modrinth.com/mod/dynamic-fps) - 백그라운드, 잠수, 닫은 상태일때 FPS 제한을 설정함. 본인은 20FPS 설정하는편.

Gamma Utils 또는 Methane(**둘 서로 호환안됨**) 밝기를 최대치로 설정.

ItemSwap - NEU에 있는 아이템락 그거

[Model Gap Fix](https://modrinth.com/mod/modelfix) - MC-73186(1.8~) 버그를 고치는 아이템 모델 버그 픽스

[No Chat Reports](https://modrinth.com/mod/no-chat-reports) - 채팅 신고가 불가능하게 만듬.

No Double Sneak - 웅크리기 2번하는 성가신 버그 픽스

NoChangeTheGame - 게임의 대부분 역학을 1.8에 맞춤(수영 금지, 엎드리기 금지)

Particle Core - 파티클 세부 설정 가능

Remove Reloading Screen - 리소스팩 리로딩할때 모장 로고 숨김

Simple Health Bar - 체력바를 멋지게 바꿈. 흡수체력 지원.

Slyde - 모장에서 정한 설정 값을 우회가능.(밝기 1300%, 렌더 거리 1 등...) Cursed한 모드라 설정 잘못 만지면 크래시 발생함.

Tooltip Scroll - 툴팁을 스크롤하는 모드. 하픽 스블 특성상 툴팁이 오지게 긴 경우가 많아서 필수.

[Zoomify](https://modrinth.com/mod/zoomify) - 줌모드

# 절대로 쓰지 말아야하는 모드.
OptiFine, OptiFabric - 모드 호환성이 그냥 개박살난다. 저거 넣는 순간 충돌함. 굳이 쓰고싶다면 여기 모드 싹다 빼고 옵티파인만 넣어라

LunarClient, LabyMod, Feather Mod 같은 클로즈드 소스 모드. 호환성 문제도 있고 대체 모드도 언제든지 있음.

Essential Mod - 모드가 이거 깔아달라고 협박하는거 아니면 전혀 쓸모없고 오히려 최적화, 호환성 문제만 야기시킴.
